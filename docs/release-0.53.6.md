# Navidog 0.53.6 ER 建模工作区

2026 年 11 月 21 日

## 打开与编辑模型

- 从顶部 **建模 → 新建 ER 模型** 选择数据库类型和版本。从 **建模 → 从数据库逆向导入** 选择连接后，按 Schema、表名条件或确切的表名选择导入范围。也可以右击数据库、Schema、表目录或表，然后选择 **逆向到 ER 图**。
- 左侧支持按表名、Schema 和分组筛选。选中列表项时画布定位到对应节点，点击图中节点时表列表会同步选中。滚轮缩放，拖拽空白处平移，拖拽节点调整位置，双击节点可编辑。
- 模型可按表名前缀、Schema 或自定义分组。画布可切换关系重力＋网格、名称网格和依赖分层。使用 **重排** 会重新计算位置，已手动移动的节点也会重新布局。
- 支持表、视图、列、主键、外键、索引和 CHECK 约束。关系工具可以建立多对一、一对一以及通过中间表实现的多对多关系。导出或移除对象之前可以先保存独立的 `.naver.json` 文件，打开的模型草稿也随 Navidog 工作区恢复。

## 生成 SQL 和导出文档

- **生成 SQL** 提供相对导入快照的差异 DDL，以及用于正向建模的完整 CREATE。生成时检查对象重名、外键引用、键和字段兼容性。循环外键会在相关表创建后添加，视图依赖可识别时会按依赖排序。
- 可复制、保存完整 SQL，或把它送到查询页手动审阅和运行。对于依赖完整结构的变更，可先在左侧选表并点击 **读取完整结构**。生成差异采用导入时的基线，服务器有并行 DDL 时应核对并重新读取。
- 导出可以选择 PDF、Word、Markdown 或同时生成三种。每个分组生成一张独立 PNG，文档同时包含表、字段和关系说明。跨组关系保留在文字说明中。缩小的概览保留节点位置，字段详情保存在文档和模型内。

## 验证范围

- 5 万张合成表和 49,999 条关系在本机测试中，绑定及重力网格布局约 69 毫秒，全图概览绘制约 7 毫秒，局部放大后的重绘约 4 毫秒。这些数值不包含服务器目录读取和系统首次字体加载。
- SQLite、PostgreSQL、MySQL、MariaDB 的逆向导入和差异 DDL 已在隔离数据库验证。Oracle、SQL Server 和 OceanBase 提供目录适配，实际可读元数据取决于服务端版本和权限。序列、函数、分区策略等高级对象不属于本版的批量模型迁移范围。
- PDF 与 Word 样张已渲染核对，Markdown 以相对路径引用 PNG。为保证导出内存上限，大分组的概览按最大 4,096 像素缩放。
