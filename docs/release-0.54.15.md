## English

- SQL previews for table design, conversion, optimization, execution-plan requests, database objects, ER models, and formatter settings share a monospaced view with highlighting, formatting, and copy actions.
- The formatter runs in the background with the preview's dialect and style. Table design, database properties, and drop operations use their original definitions.
