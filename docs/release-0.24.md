# Navidog 0.24：标签关闭与连接编辑

每个工作标签使用 Qt 标准关闭按钮，固定在标签右侧。点击、菜单与快捷键共用关闭流程，拖动标签后也按对应页面关闭。最后一个标签可以关闭，重启后保留空工作区。

编辑连接时，如果该连接仍有打开的标签，将提供：

- **关闭相关标签并编辑**：确认相关草稿后关闭标签，释放查询会话，再打开连接设置。
- **返回自行处理**：切换到相关标签，保留全部内容。
- **取消**：保留当前工作区。

SQL 修改可保存到文件、不保存关闭或取消；表结构、对象定义和数据编辑分别确认放弃。批量关闭会先收集全部确认，任何一步取消均不关闭本批标签、不回滚事务；已经主动保存的 SQL 文件仍保留。

查询有未提交事务时，会明确提示回滚；正在执行的查询可停止后关闭，其他查询标签继续可用。正在读取或保存对象的页面仍需等待操作结束或先停止。关闭不会撤销数据库已经提交的修改。

连接配置、SQL 和对象设计草稿继续使用原有工作区保存方式。更新通过正常退出保留最新工作区，不用旧快照覆盖用户新操作。
