# Navidog 0.53.103

- 左侧导航树支持拖曳调整分组、同组连接和未分组连接的顺序，重启后保留。
- 拖到分组名称上可移入分组，拖到其他连接旁可移动到指定位置，拖到列表底部空白处可移到未分组列表末尾。分组始终位于未分组连接上方。

## English

- Drag to reorder groups, connections within a group, and ungrouped connections. The navigation order is saved across restarts.
- Drop onto a group to join it, next to another connection to place it there, or onto the empty area below the list to ungroup it. Groups stay above ungrouped connections.
