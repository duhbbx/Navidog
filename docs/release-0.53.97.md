# Navidog 0.53.97

- 数据库与 Schema 节点增加 SQL 命令列、运行 SQL 文件、数据库字典和按表统计的查找工作区。
- SQLite、MySQL 系与 PostgreSQL 可以转储结构或结构与数据。转储使用相应数据库客户端工具。
- 数据库属性编辑支持 MySQL 系默认字符集和排序规则、PostgreSQL 所有者、SQL Server 排序规则及 SQLite 用户版本。

## English

- Database and schema nodes gain a SQL console, SQL file execution, a data dictionary, and a search workspace with per-table match counts.
- SQLite, the MySQL family, and PostgreSQL offer structure-only or structure-and-data SQL dumps through their database client tools.
- Database properties can change MySQL-family default character sets and collations, PostgreSQL database owners, SQL Server database collations, and the SQLite user version.
