# Navidog 0.53.89

- 单击左侧导航树的目录名称只选中目录。双击表、视图、函数和存储过程等对象目录会展开节点，并在右侧打开对应的对象列表。再次双击可收起目录。

## English

- Single-click a folder name in the navigation tree to select it. Double-click an object folder, such as Tables, Views, Functions, or Procedures, to expand it and open its object list in the workspace. Double-click again to collapse it.
