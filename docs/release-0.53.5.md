# Navidog 0.53.5

2026 年 11 月 20 日

## 桌面工作台

- 修复关闭连接后快速展开其他节点时目录加载请求丢失的问题。展开请求会排队，连接关闭后可以继续浏览其他节点或重新打开原连接。关闭连接会保留查询文本和本地草稿。
- 每次启动在工作区目录更新 `startup.log`，记录 Qt 初始化、设置与连接读取、示例库、窗口构建、工作区恢复以及首次绘制。`elapsed_ms` 为分段耗时，`total_ms` 为自进入 `main()` 起的累计耗时。
- 恢复已有工作区时跳过临时示例查询页。在本机使用已有示例库的隔离工作区测试，空标签工作区首次绘制耗时从 560 ms 降到 354 ms，均为三次实测的中位数。恢复 12 条查询标签的单次实测中，恢复标签用了 718 ms，首次绘制耗时约 1.12 秒。

## MySQL 游标

- 函数和存储过程支持静态游标声明、打开、取数和关闭，包括 `FETCH FROM` 与 `FETCH NEXT FROM`。语义检查按作用域绑定游标和目标变量，并区分定义错误与调用阶段提示。
- 例程 AST 和统一 IR 保留游标查询、目标变量及作用域信息，支持生成 MySQL SQL。编辑器会在游标操作和 `FETCH INTO` 处提供候选项。含游标的跨方言转换需要目标方言的生命周期与错误处理映射。
