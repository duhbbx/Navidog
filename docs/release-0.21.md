# Navidog 0.21 本轮交付

日期：2026-11-17。Mac 安装位置：`/Applications/Navidog.app`。本轮以 MySQL、PostgreSQL、Oracle 为主要验证目标，参照本机 Navicat 的桌面布局和操作方式继续开发；当前仍未覆盖 Navicat 的全部功能。

## 快速操作

- 查询工具栏“查找”或 Cmd/Ctrl+F 打开查找；编辑菜单提供替换、上下一个匹配。
- 选中多行按 Tab / Shift+Tab；编辑菜单“切换行注释”使用 Cmd/Ctrl+/。
- 编辑菜单“转到行”使用 Cmd/Ctrl+Alt+L。
- 结果单元格双击 / F2 查看，右键复制或带列名复制。
- SQL 文件使用 Cmd/Ctrl+O、S、Shift+S；关闭标签使用 Cmd/Ctrl+W。
- “解释”使用独立会话，不执行原 DML，也无法查看当前查询页的临时表或未提交结构。
- 结果导出只包含当前已加载缓存；有截断提示时不能视为完整备份。

## 验证与用户数据

- 0.21 常规六套 CTest 均通过，用时 22.67 秒。其中核心、界面、隔离 PostgreSQL 15 与 MySQL 9.5 实际运行；MariaDB / Oracle 默认入口按环境跳过，不能据此视为实例验收。
- 本轮另行启用官方 MariaDB 11.4.11 自有临时容器，13 项实际测试通过；Oracle Free 官方自有临时容器，11 项实际测试通过。覆盖真实对象、数据写回、事务、并行、取消等；最近的 0.20 / 0.21 修改仅在编辑器与界面命令，不改数据库执行逻辑。
- Mac 原生安装版验证：结果右键、类型表头、JSON、MariaDB 连接页、查找替换及一次撤销、多行缩进 / 注释、跳转到第二行，并执行当前语句得到 `31`。
- 用户原有 8 个连接和 8 个工作标签保留；更新前后连接文件哈希一致，8 份标签草稿状态精确相等。每次替换前保留新鲜私有备份，没有回灌旧会话覆盖用户内容。
- 所有自动写入验证使用项目示例库、临时本地集群或自有容器。没有连接用户业务数据库做写入测试。
