# Navidog 0.28：本地元数据缓存与校验

查询窗口新增“同步元数据”。表、视图、字段、函数、存储过程与参数由官方驱动后台批量读取，保存到本地 SQLite；输入时只用不可变内存快照校验。

红色波浪线表示本地语法错误；橙色表示缓存中的表字段 / 限定例程未找到、字段歧义或参数个数疑点。鼠标悬停可看原因与刷新说明。函数重载、默认参数、OUT / INOUT 和可变参数记录到缓存；本批检查参数数目，尚无完整类型重载推导。

缓存按连接身份、数据库、Schema 隔离。TTL 为 5 分钟，已连接的当前查询页每 15 秒检查是否需要刷新，失败逐步退避。DDL / 对象修改 / 权限或连接配置变化会失效；事务、临时对象、自定义会话上下文保守降级。磁盘旧缓存须本次会话重新验证，过期和不完整目录不用于否定判断。恢复标签、编辑 SQL 和读取缓存均不自动连接业务数据库。

存储与更新规则、预算和实际边界见 [设计文档](design/metadata-cache.md)。只存结构名称与类型等目录信息，不存业务行、SQL 正文、例程源码或口令。

验证：临时 SQLite 与隔离 PostgreSQL / MySQL 的真实采集、字段绑定、函数重载 / 默认参数及过程参数；缓存原子替换和失败回滚、未来格式保护、失效 / 过期 / 部分目录、身份隔离、刷新期间失效拒收、离线读取不连接，以及固定批量读取次数。Qt 界面覆盖橙色诊断与失效撤销、同步按钮和事务降级。27 组独立编译器用例与 CLT 21 ASan / UBSan 通过；Win7 C++17 交叉构建与依赖审计通过，当前版本运行验收待完成。Oracle / SQL Server 本批尚未连实例验收。

本批不覆盖 Oracle 包 / 同义词 / 链接、SQL Server EXEC、完整排序规则、权限、类型推导或全部引擎版本。外部客户端改结构仍依赖 TTL / 手动同步，局部目录缓存不是服务器强一致视图；手动 AST 和执行链路继续遵循原有原文执行规则。
