# Navidog 0.23：解析接入 SQL 执行

运行 SQL、运行当前语句或查看执行计划时，后台现在会自动调用对应方言解析器。结果区新增 **SQL 分析** 标签，显示本地识别状态、查询 / 表达式数量、涉及对象及实际执行状态。

原始 SQL 仍交给官方驱动执行。本地解析未覆盖、失败或超限不会阻止数据库执行；最终校验、权限、数据结果与数据库错误仍由服务器决定。不会为了本地分析增加网络元数据读取、提交事务或自动改写 SQL。

本批新增 CASE、非递归 SELECT CTE、派生表、标量 / EXISTS / IN 子查询、DISTINCT 函数参数，以及关联字段 / 别名遮蔽 / JOIN 可见性。统一 Model 使用平坦查询池，增加推断列预算、不可变结构共享和协作式取消，避免嵌套 SQL 无限展开。详细范围见 [SQL 编译基础库](sql-compiler.md)。

另修复手输数据库 / Schema 名称后回车，名称可能显示在下拉框但实际被当作默认值的问题。兼容无绑定数据的旧项，并禁止控件自动插入这种项。

验证包含独立编译器、嵌套作用域与资源上限、Qt 输入 / 多结果 / 事务界面，以及自有 SQLite、隔离 PostgreSQL 15 和 MySQL 9.5 的真实执行。暂未覆盖的窗口函数也验证能正常交给数据库运行。Oracle / MariaDB 本轮未启动容器；SQL Server 未进行服务器实连。Win7 运行与物理机回归仍待验证。

尚未实现完整 SQL 转换、DML / DDL / 窗口 / 递归解析、新的语法格式化、语义补全或编辑器下划线诊断。现有编辑器轻量功能继续保留。


本轮验证：7 套 CTest 全部通过，独立编译器包含 15 组用例和 2000 份畸形输入，CLT 21 ASan / UBSan 通过，CLI AST / Model 的嵌套引用和父作用域 JSON 核对通过。Win7 交叉构建与打包审计通过，运行验收仍待做。

Mac 已安装 0.23，并确认最新的 11 个原有标签、草稿和数据库上下文恢复，新增“SQL 分析”入口可见。用户正在操作安装版，未继续切换连接做原生示例查询；完整执行链路由 Qt 界面测试和隔离实例覆盖。保留用户当前新增查询，不再改动窗口。旧安装包与暂存目录已清理，私有工作区备份保留。
