# Navidog 0.39.0：操作符、关系元数据与 Hep

本轮交付原生 C++ 编译 / 规划基础的可用子集，**Calcite 全部功能尚未移植完成**。[功能矩阵](calcite-port.md) 与 [逐规则库存](calcite-port-inventory.json) 固定为官方 1.42.0 发布归档，列明未实现的类型、规则、去相关、物化视图、适配器、联邦与执行运行时等部分。

## 共享函数与作用域事实

- 内建函数 / 聚合 / 窗口目录集中维护方言可见性、参数数量、粗粒度返回类型和易变性，供分组 / 窗口检查、类型族推断和补全复用。它还不是完整的 SqlStdOperatorTable / 类型工厂。
- PG、SQLite 与 SQL Server 的已知服务器例程类别进入不可变元数据、Binder 和拥有数据的 IR；旧 / 缺失类别保持 Unknown。PG 文本布尔值转为显式 0 / 1；SQLite 固定参数重载优先于变参，区分 `max(x)` 聚合与 `max(x,y)` 标量。
- 原生 SQLite 缓存增加附属例程事实表，保持旧对象列序和全局工作区格式版本；快照替换 / 删除级联处理，避免旧事实残留。
- 自定义函数即使与内建函数同名，也不会套用内建跨方言映射；对象不必已在当前服务器上存在的转换行为继续保留。过程局部变量 / 参数上下文继续沿用现有 Binder，不把全量过程语言语义描述为已完成。

## 关系元数据与规则

`RelMetadataQuery` 提供独立有界缓存：硬行数上下界、受限唯一键谱系、部分非空信息与效果边界。直接投影 / 别名保留已证明的键；统计估计不能成为去重 / 删除算子的证明。检查关系引用 / 元数 / 循环、预算和取消；既有节点不可变，追加候选不会使旧缓存指针失效。

Hep 在完整基线建立后运行，再把已完成的等价结果纳入原有 Memo / Volcano 成本搜索。包含五类有条件规则：相邻可移动过滤合并、恒等投影移除、相同相邻排序移除、常量分页合并、已证明唯一 / 至多一行时移除 DISTINCT。保留原 SQL、原始 IR / DAG 和基线；不连接 / 执行 SQL，也不直接发布未经验证的改写 SQL。

Hep API 可配置规则顺序、遍历方向、遍数和匹配上限。统一设置的“SQL 分析与优化”与分析弹窗新增开关；报告记录阶段、完整性、实际配置与规则来源。分页合并拒绝未知副作用 / 潜在抛错表达式，不能仅凭 immutable 就改变可观察求值边界。不是全部上游 Hep 指令 / 规则的移植。

## 验证和安装

- 完整 **12 组 CTest 通过，35.58 秒**，包括隔离 PostgreSQL 15 临时集群。最后效果边界补强后，相关六组（完整 GUI 与五组编译 / 优化库）再通过，25.40 秒；新增用户同名函数转换反例另通过。
- 五组编译 / 优化测试通过 AddressSanitizer，4.47 秒；新增转换用例追加复验通过，0.76 秒。统一设置保存、优化弹窗端到端两项 GUI 用例通过 ASan（计数含初始化 / 收尾共四项）；厂商 Qt 泄漏检查关闭，不算完整泄漏审计。
- 真实服务器验证使用测试自己建立的临时 PostgreSQL 集群和临时 SQLite 数据库，包含自定义聚合 / 标量 / 返回集合函数；MySQL / MariaDB / Oracle 的对应套件在本轮未配置真实实例、服务端用例跳过，不能把 CTest 套件通过当作这些服务器的新功能实测。SQL Server 本轮也未作真实实例验收。
- macOS 新版签名核验，正常退出旧版后替换 `/Applications/Navidog.app` 并启动，只有一个运行实例；安装二进制与最终打包二进制相同。退出前后均保留私有数据库 / 密钥备份，保存的三个原标签与 SQL 哈希保持一致。
- 原生安装版在独立分析弹窗输入 `SELECT * FROM owned_hep_probe;`，开启 Hep 得到 `HepProjectRemove` 轨迹及候选相对成本 8900 / 基线 9900；关闭后无该轨迹、候选回到 9900。统计明确为 assumed，无数据库连接 / SQL 执行；关闭验证弹窗后保留三个原标签及零会话。统一设置的保存与开关映射由 Qt 端到端 / ASan 测试覆盖，未冒充已完成原生分类点击的视觉验收。
- Win7 x64 Qt 5.15 / C++17 交叉构建通过，10 个 PE 导入审计通过，无 UCRT。包仍仅含 SQLite 驱动，本版未在 Win7 客户机运行验收。
