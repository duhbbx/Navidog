# Navidog 0.53.98

- 数据库和 Schema 的数据字典可导出为 PDF、Word（.docx）或 HTML。
- PDF 和 Word 包含目录及字段表格。表注释位于表名下方，字段注释位于对应字段行，导出时保留原有换行。
- 连接右键可跨数据库和 Schema 查找对象及字段名称，并查找视图、函数和存储过程的目录定义。查找优先使用本地元数据缓存。

## English

- Export a database or schema dictionary as PDF, Word (.docx), or HTML.
- PDF and Word include a table of contents and field tables. Table comments appear below table headings, and column comments appear in their corresponding rows. Line breaks are preserved.
- Search a connection for object and column names or the catalog definitions of views, functions, and procedures. Database and schema filters are optional, and search uses the local metadata cache first.
