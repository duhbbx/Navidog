# Navidog 0.54.14

- 查询会话控制器管理查询、事务、执行计划和本地解析的请求、取消及结果路由。
- 工作区会话存储负责保存和读取标签草稿、窗口与布局状态，兼容已有工作区。
- 查询页和对象定义页使用各自的 SQL 选区及数据库上下文打开转换和本地优化。

## English

- A query session controller manages requests, cancellation, and result routing for queries, transactions, execution plans, and local analysis.
- A workspace session store loads and saves tab drafts, window geometry, and layout using the existing workspace format.
- Query and object definition panes open conversion and local optimization with their own SQL selection and database context.
