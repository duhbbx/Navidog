# Navidog 0.53.99

- 数据字典改为五步向导，支持多范围勾选、对象筛选和调整文档顺序。
- 提供五套模板和纸张预览，可设置封面、目录、页眉页脚、正文和纸张。PDF、Word 和 HTML 共用所选内容。
- 对象范围、顺序、版式和封面图片可保存为本地方案，也可导出和加载 JSON 配置文件。

## English

- The five-step data dictionary wizard supports multiple database or schema scopes, object filtering, and document ordering.
- Choose from five templates and configure the cover, contents, running headers and footers, body, and paper from a live preview. PDF, Word, and HTML use the same selection.
- Save scopes, ordering, layout, and cover images as local presets or exchange them as JSON configuration files.
