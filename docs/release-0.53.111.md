# Navidog 0.53.111

- 将新建、编辑和复制连接的对话框流程及配置保存交给独立的连接控制器。
- 主窗口在连接保存后更新导航树和查询标签，并协调关联标签关闭与旧会话失效。

## English

- A connection controller owns the create, edit, and duplicate workflows and saves connection profiles.
- The main window coordinates related tab closure, old session invalidation, and workspace updates.
