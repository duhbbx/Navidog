# Navidog 0.38：离线转换、右键入口与连续补全

## 对象可以尚未创建

转换使用操作内的 `ConversionCatalog`：源目录可辅助提供已知形状与类型，但当前服务器没有某张表 / 某个例程不再阻止转换。目标生成与重新解析仍离线进行，不创建对象、不执行语句。

普通编辑器的目录诊断保持独立；脚本明确声明的字段、程序局部变量和已知参数 / 类型仍检查一致性。未知对象不代表所有改写都可证明：需要展开未知 `*`、没有实现的函数映射、复杂过程或缺乏类型证明的转换仍明确拒绝，不返回半截结果。

## 编辑器右键

查询与对象定义编辑器增加“SQL 转换…”和“SQL 本地分析 / 优化…”，保留原有编辑菜单。使用选区或全文副本，复用工具栏入口和数据库上下文，不执行 SQL、不改原文。

macOS 使用共享原生菜单适配，菜单关闭后才分派打开弹窗的命令。没有相应工具的展示 / 临时编辑器不添加无效入口。本地分析仍有语句范围限制，未覆盖的完整例程等输入会明确报告限制，不伪造成本。

## 一个字符触发与键盘操作

- 默认最短前缀为一个字符；点号、部分子句后的空格和输入法提交也可触发。70ms 合并请求，输入时只读本地快照，保留有界工作线程 / 请求 / 载荷预算。
- 旧的两字符默认阈值迁移为一个字符，三 / 四字符阈值保留；保存行为版本后，用户之后明确设置的阈值不再被迁移覆盖。
- 弹窗在当前行下方增加至少 6px 间距，屏幕边界由 Qt 调整。Tab、Enter / Return 接受当前新鲜候选，Shift+Enter 换行。
- Esc 立即隐藏并取消待显示请求；下一次输入可以重新弹出，不会永久关闭提示。
- 文本改变即废弃旧替换范围。后续请求存在时保留原生弹窗，结果刷新不先将模型清空至零行，避免关闭 / 重开导致焦点丢失。接受 / 取消时恢复编辑焦点，只允许接受对应当前文档版本的候选。
- 字符串 / 注释中抑制候选；统一设置可以关闭自动补全、调整最短前缀。

语义场景确实需要逐类扩展，但不是给每个字符单独写一个分支。当前按关系引用、表达式、限定列、别名、调用、类型、对象声明与程序符号组织候选；优先解析作用域，不完整输入使用受限恢复。完整容错文法、全部方言版本及所有内建签名尚未完成。

## SHOW 与 Calcite

MySQL `SHOW TABLES` / `SHOW FULL TABLES` 等仍列为后续扩展。模式 / 权限可见性、输出列及 LIKE / WHERE 规则需分别建模，不直接替换成其他引擎的目录 SQL。本地未覆盖不代表 MySQL 不支持，正常执行仍交给官方驱动。

Calcite 尚未完整移植。当前是独立 C++ 实现部分公开架构概念，见 [优化器设计](optimizer-design.md)。

| 当前已有 | 仍待实现 / 完善 |
| --- | --- |
| SQL Model 到关系代数 DAG | 完整类型、隐式转换、版本化函数 / 操作符目录 |
| 有界 Memo、规则轨迹、按排序性质搜索 | 全部优化规则、完整去相关与子查询改写 |
| 过滤下推、内连接交换 / 结合、受限常量规则 | 物化视图匹配 / 重写和更多等价性证明 |
| 若干扫描 / 连接 / 聚合 / 排序候选 | 完整适配器、联邦查询和分布式规划 |
| 统计与 CPU / I/O / 内存相对成本 | 直方图、多列相关性和成本校准 |
| 建议、候选 / 基线、JSON 报告 | 独立物理算子执行运行时 |

Volcano 规划器的 Memo / 规则搜索，与执行查询的迭代器引擎是不同部分；当前没有独立 SQL 执行引擎。服务器计划由数据库产生，本地成本不是实际耗时或服务端一定采用的方案。
