# Navidog 0.53.93

- 「帮助 → 检查更新」查询 GitHub 的最新正式版本。自动检查在窗口显示后延迟发起，可在常规设置中关闭。
- 「帮助 → 查看启动日志」显示本次启动各阶段耗时，支持复制和打开日志目录。

## English

- Help → Check for Updates checks the latest stable GitHub release. Automatic checks start after the window is shown and can be disabled in General settings.
- Help → View Startup Log displays the timings for this launch, with actions to copy the log and open its directory.
