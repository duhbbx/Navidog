# Navidog 0.22 与 SQL 编译基础阶段

桌面 0.22 已安装到 `/Applications/Navidog.app`，保留更新前最新的 10 个工作标签和草稿。

- 选中左侧节点后，顶部“查询”、新建查询及查询菜单均创建真正的查询标签，继承连接、数据库和 Schema。
- 查询标签各自拥有连接 / 数据库 / Schema 上下文，可切换或输入数据库和 Schema。PG 使用标签会话的 search_path，Oracle 使用 CURRENT_SCHEMA；更换上下文时保留 SQL，活动事务需确认回滚。
- 元数据加载期间仍可创建、编辑及执行查询，“停止加载”只取消目录读取。
- 延后右键菜单到鼠标释放事件返回后打开，错误窗口使用可复制详情的非模态弹窗，处理菜单 / 弹窗导致其他区域不能点击的问题。
- 修复对象页恢复时覆盖相邻表设计标签标题的问题，保留表设计内容。

常规六套 CTest、隔离 PG / 官方 Oracle 自有容器测试通过；Mac 安装版验证查询创建、上下文控件、关闭右键菜单后的再次操作及工作标签恢复。原生下拉列表未由辅助工具完整操作，具体切换由界面测试和真实 PG / Oracle 核对。测试容器已清理，OrbStack 恢复为测试前的停止状态。

另新增独立 C++17 SQL 编译基础库：各方言 Parser、递归下降、源码 AST、统一 Model、源码 / AST / 名称上下文、基础 Catalog 和单层作用域。当前只支持受限 SELECT，不包含完整 SQL 转换、格式化、补全或诊断界面，也未接入已安装编辑器。使用方式和准确支持范围见 [SQL 编译基础库](sql-compiler.md)。

基础库通过 12 组测试（内含 2000 份畸形输入）、CLT 21 ASan / UBSan、CLI JSON / 失败退出码，以及 Win7 C++17 交叉编译。新的 CLI 未在 Win7 原生运行验收。Win7 0.22 桌面包仍为 SQLite 兼容版，交叉编译不等于本版运行验收。
