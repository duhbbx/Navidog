# Navidog 0.29：SQL 格式化与原生设置

查询工具栏与对象定义编辑页新增“格式设置”，菜单“查询 → SQL 格式设置”也可打开。弹窗采用左侧配置大类、右侧对应表单，右侧下方可切换当前 SQL、查询、DML / DDL、函数与存储过程示例，异步查看效果。设置在本机保存，不要求用户编辑配置文件。

配置包括易读 / 紧凑 / 展开预设、缩进与续行宽度、空格 / Tab、目标行宽、关键字大小写、字段和参数列表布局、逗号位置、JOIN / 子句 / 布尔条件换行、子查询与 CASE 缩进、赋值与别名对齐、语句空行、换行符和 PG 函数体排版。保存生效，取消不修改设置。

支持选区或全文格式化，一次撤销。任务在工作线程执行；等待期间编辑 SQL 或切换上下文会拒绝过时结果。不会运行 SQL。排版前后核对 token、字符串、注释和标识符。无法安全处理时保留原文并提示。

常见覆盖：SELECT / JOIN / CTE / 子查询 / CASE；INSERT VALUES / INSERT SELECT、UPDATE、DELETE；表 / 索引等 DDL；MySQL 函数与过程 / DELIMITER；Oracle PL/SQL 参数、声明、分支、循环和异常；SQL Server BEGIN / END、TRY / CATCH；PostgreSQL LANGUAGE SQL / PLPGSQL 的美元引号函数体。其他语言体、动态 SQL 与普通字符串不做重写。此覆盖是保留原文的布局支持，不能当作完整过程语言语法或语义检查。大小写敏感方言的未完整解析文本保留关键字原大小写。

同时包含 [0.28 元数据缓存](release-0.28.md)：服务器表 / 字段 / 函数 / 过程 / 参数批量同步到本地 SQLite，并在可验证且未过期时参与编辑器校验；有失效与事务降级机制。Oracle / SQL Server 本批无真实实例回归。

按用户要求移除了系统钥匙串 / 凭据管理器使用。数据库、SSH 与 HTTP 密码仅在本次运行内存中复用；重启后第一次需要连接时输入数据库凭据。旧配置保存标志自动迁移，原有系统钥匙串条目不读取也不删除。

架构参考 Clang 的源位置 / ASTContext、方言前端、Binder、Lowering 和规范 SQL IR；自有递归下降与运算符优先级解析器，不是 LLVM SSA 或 JIT。格式化使用独立的源 token 布局层，不经 IR 重建 SQL，避免丢失原文。

验证记录见 `.cache/sql29-*.log`；仅使用临时 SQLite、隔离 PG / MySQL 和本项目示例库，不连接用户业务库。Win7 包只含 SQLite；交叉构建不等于 Win7 运行验收。

安装验收：已替换 `/Applications/Navidog.app` 并验证仅有一个进程，保留更新前刚保存的 12 个标签和草稿。原生窗口确认左侧分类 / 右侧表单及过程预览，MySQL DELIMITER 存储过程格式化与一次撤销成功；关闭独立测试标签后 session.json 与更新前最终保存状态逐字节一致。未运行用户编辑器中的 SQL，也未连接用户业务库。配置保存 / 取消和分类切换由 Qt 界面测试覆盖；本轮 CUA 没有完成所有下拉控件与元数据同步的手工验收。

测试：7 个 CTest 套件通过（MariaDB / Oracle 未配置实例时按测试内条件跳过连接部分）；独立编译器 29 组用例，覆盖三种预设、多种逗号 / 换行 / 缩进选项、复杂对象幂等性、注释 / 优化提示与字面量保留、资源限制和取消。CLT 21 ASan / UBSan 通过；最终增加对象编辑页入口后 Qt 界面测试再次通过。Win7 SQLite 兼容包交叉构建成功并审计 10 个 PE 依赖，未进行 0.29 Win7 客户机运行回归。
