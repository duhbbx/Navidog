# Navidog 0.53.84

- 左侧导航树改为独立组件，负责搜索、展开和折叠、对象加载队列、目录刷新及右键菜单的生命周期。主窗口通过组件接口同步查询、数据和对象编辑标签。

## English

- Extracted the navigation pane into a dedicated widget responsible for filtering, expansion, queued catalog reads, refreshes and context-menu lifecycle. The main window coordinates query, data and object editor tabs through the widget interface.
