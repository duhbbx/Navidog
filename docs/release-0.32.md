# Navidog 0.32 — 独立语句校验与明显的错误标记

修复 `SELECT … FROM orders …;` 后面出现孤立 `a` 等不完整语句时，整个编辑器被降为仅语法检查的问题。使用有效且对应当前上下文的元数据快照，对前面的完整 DML 单独校验表、字段和例程；错误语句自己的语法诊断继续保留。未知语句之后的语句仍保守跳过目录校验，DDL、会话设置、事务控制及动态执行所在批次继续暂停共享目录诊断。旧缓存、未验证 / 失效 / 不完整目录不能据此断言对象不存在。

语法错误和当前目录中的对象问题统一采用高对比红色波浪、浅红底色、行号红点。保留诊断来源，悬停仍区分本地语法错误与可自动刷新的元数据提示。额外绘制 1.8 个逻辑像素宽的抗锯齿波浪，按可见文本行、换行与水平滚动定位，适配高分屏；不改变文本、撤销历史和文件内容。解析器未覆盖的语法仍使用灰色点线。

回归用例包含原场景的 `orders` / `customers` 与末尾孤立字符、未知语句屏障、后续 DDL 的保守行为、未验证快照不误报、悬停定位、标记清除，以及表名下方红色波浪的实际渲染检查。测试使用项目自有临时库和构造目录快照；不连接用户业务库进行测试。
