# Navidog 0.53.110

- 查询标签负责呈现执行结果、消息、导出上下文和事务状态。
- 表设计和数据编辑标签负责处理读取、提交结果及各自的控件状态。主窗口继续负责请求路由和跨标签刷新。

## English

- Query tabs present execution results, messages, export context, and transaction state.
- Table design and data tabs apply their own load and save results. The main window routes requests and coordinates refreshes across tabs.
