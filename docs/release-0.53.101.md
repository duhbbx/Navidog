# Navidog 0.53.101

- 左侧导航树统一处理连接分组和表分组的新建、重命名、移动和删除，并保存到现有的本地配置。
- 删除分组后，连接和表返回各自的上一级列表。

## English

- The navigation tree now manages creation, renaming, movement, and deletion for connection and table groups, using the existing local settings.
- Removing a group returns its connections or tables to their parent list.
