# Navidog roadmap

[中文路线图](#中文路线图)

## Next

- Expand real-server testing for the existing database adapters, including authentication, catalog browsing, server plans, and cancellation.
- Complete install and upgrade verification for desktop packages. Validate the UOS, Kylin, and HarmonyOS builds on their target systems.
- Extend SQL completion, diagnostics, and conversion for database-specific DDL, routines, and procedural scopes. Document unsupported constructs as they are encountered.
- Expand regression coverage for ER reverse engineering, schema diffs, and large-model rendering and export.

## Later

- Broaden supported database families once their drivers and core workflows can be tested.
- Improve local plan analysis and query optimization advice, with benchmarks for representative workloads.
- Add database comparison and migration workflows with SQL previews and validation before applying changes.

## 近期

- 扩充现有适配器的真实数据库测试，覆盖认证、目录浏览、执行计划和取消查询。
- 验证桌面安装、升级流程，以及统信 UOS、麒麟和鸿蒙上的构建与运行。
- 扩展数据库特有 DDL、函数、存储过程和过程作用域的补全、诊断与转换，并记录尚未覆盖的语法。
- 扩充 ER 逆向工程、结构差异、大模型绘制与导出的回归测试。

## 后续

- 在驱动和核心工作流可验证的基础上，逐步增加数据库类型。
- 改善本地计划分析与 SQL 优化建议，并记录代表性场景的基准数据。
- 增加数据库结构比对和迁移能力，支持在应用变更前预览和验证 SQL。
